# Cómo usar los tests

1. Descargar la carpeta con los archivos de referencia desde el siguiente enlace:
   https://drive.google.com/drive/folders/14djVinbZOKVpMn6CNWOJScNvpGAYyGsJ?usp=sharing

2. Mover la carpeta descargada a `src/bin/`.

3. Verificar que la estructura de carpetas quede de la siguiente forma:

   ```text
   src/
   └── bin/
       └── references/
           ├── insert_1.ref
           ├── insert_2.ref
           ├── insert_3.ref
           └── ...

4. Compilar el proyecto.

5. Ejecutar el test que se quiera probar.
