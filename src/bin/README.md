# Cómo usar los tests

1. Borrar su base de datos actual
2. Descargar la carpeta con los archivos de referencia (https://drive.google.com/drive/folders/1RyjM4ZclwSiS1Gqrg-R5lgQRvoJ769GW?usp=sharing) y dejarlos en la rama principal (archivos de la base de datos deben estar en data/example_db)
3. Compilar
4. Ejecutar el test que se quiera probar
